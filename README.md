# Threads 表情搬运助手

把公开 Threads 帖子主贴中的表情媒体提取出来，排除普通照片和回复区媒体，精确去重后生成一个纯表情 ZIP。解压后将表情文件发送到微信，再逐个手动添加。

## 能做什么

- 接收公开的 `threads.com` 或 `threads.net` 帖子链接。
- 优先识别主贴中的 GIF、Giphy、Tenor、WebP 和透明 PNG 表情。
- 排除普通轮播照片、引用帖截图、头像、图标、回复区和相关帖子媒体。
- 按文件内容进行 SHA-256 精确去重。
- 最终只交付一个扁平 ZIP，内部文件按 `sticker-001.gif` 的形式编号。

## 不会做什么

- 不要求或保存 Threads Cookie、密码及登录凭据。
- 不修改微信文件、数据库或收藏数据。
- 不会自动把表情加入微信；最后仍需在手机微信中长按表情并选择“添加”。
- 不保证拆分一张已经合成好的表情拼图。
- 不进行视觉近似去重；只删除内容完全相同的文件。

## 安装到 Codex

在 Codex 中新建一个任务，完整复制下面这段内容并发送：

```text
请使用 $skill-installer 安装这个 Skill：
https://github.com/weiweiwei123a/threads-sticker-to-wechat
```

这里已经是实际仓库地址，不需要替换用户名，也不要添加 `.git`。

## 使用方法

安装成功后新建一个 Codex 任务，先输入下面这句话，再在冒号后粘贴你从 Threads 复制的真实帖子链接：

```text
使用 $threads-sticker-to-wechat，把这个帖子里的表情整理成微信收藏包：
```

支持普通帖子链接和 Threads 的分享链接。每次处理一个帖子。

## 收到 ZIP 后怎么用

1. 下载 Codex 返回的 ZIP。
2. 解压 ZIP；不要把 ZIP 文件本身当作微信表情发送。
3. 将解压后的 GIF、WebP 或 PNG 文件发送到微信文件传输助手或任意聊天。
4. 在微信聊天中长按需要的表情，点击“添加”。微信仍需逐个添加。

## 运行要求

- Codex，以及能够渲染 Threads 并读取当前页面媒体资源的浏览器能力；只有终端、没有浏览器媒体读取能力时无法完成提取。
- Python 3.10 或更高版本；打包脚本仅使用 Python 标准库。
- 默认只处理无需登录即可查看的公开帖子。私密、已删除、地区受限或必须登录的帖子可能无法提取。

如果主贴只有普通照片、没有可识别的独立表情，Skill 不会把照片凑进 ZIP。若帖子发布的是一张表情拼图，也无法无损恢复成原始的独立表情文件。

## 输出与安全

输出 ZIP 仅包含通过签名检查的 GIF、WebP 或 PNG 文件。脚本默认拒绝覆盖已有 ZIP；只有显式使用 `--force` 才会替换同名文件。
